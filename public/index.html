Unframer

Turn any website into portable HTML, CSS and JavaScript you can host anywhere. Trackers and platform watermarks are stripped out.

Export sites you own or are authorised to export.

Up to 5 here. Unlimited when you run it yourself.

This hosted version is deliberately limited It runs on serverless functions, which stop after 60 seconds and cannot return more than a few megabytes — so it links assets to their original host rather than downloading them, and caps the page count.

For the complete export — every image, font and script downloaded, full animation fidelity on Framer sites, and a preview server bundled in — run it locally. It is one command and has no limits.
