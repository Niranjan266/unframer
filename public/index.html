This hosted version is deliberately limited It runs on serverless functions that stop after 60 seconds and cannot return more than a few megabytes, so it links assets to their original host instead of downloading them and caps the page count. For the complete export — every image, font and script downloaded, plus a bundled preview server — clone the repo and run npx tsx src/cli.ts exportsite <url>.
